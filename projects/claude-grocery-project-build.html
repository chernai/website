Claude Grocery Project

A hands-on Claude Code project — follow along, copy the prompts and code below, and try it yourself.

B. Build

Same as before — follow along step by step, each card below is one step.

Step 1

Getting Your API Key

We are building an app that can read your grocery receipts. Before the app can read anything, we need to get an API key.

  1. Go back to platform.claude.com, the place you paid for credit.
  2. On the left sidebar, click API keys.
  3. Click Create key.
  4. Name the key claude-grocery-project.
  5. Click Create.
  6. Copy the key and paste it into a txt file (just to store for a while).
Step 2

Using Your API Key

Now we need to tell your computer to use this key so the app can talk to Claude. Copy the line below that matches your terminal, paste it into your txt file, replace xxxx with your API key, and then paste the final command into your terminal.

Mac (Terminal)

export ANTHROPIC_API_KEY="xxxx"

Windows (Command Prompt)

set ANTHROPIC_API_KEY=xxxx

Windows (PowerShell)

$env:ANTHROPIC_API_KEY="xxxx"

Make sure there are no extra spaces before or after your API key before you paste it into Terminal.

Step 3

Build Your Dashboard

Now for the fun part. Claude Code is already open inside your claude-grocery-project folder, with access to your july-2026 and august-2026 receipt folders. Copy the entire box below, paste it into Claude Code, and press Enter.

Build me a dashboard called "My Groceries." Look through every receipt photo in my july-2026 and august-2026 folders. For each receipt, read every item, its price, and the date. Sort each item into a grocery category (Produce, Meat & Seafood, Dairy & Eggs, Bakery, Pantry & Dry Goods, Beverages, Household, Snacks, Other). Save everything you extract into a simple data file so the app never needs to re-scan the receipts once it's built. Then build a single, self-contained dashboard (a webpage I can open just by double-clicking it, no server or install needed) titled "My Groceries" with: 1. A summary at the top: total spent in July, total spent in August, combined total, and total number of items. 2. A table listing every single item from both months, with columns for Date, Item, Category, Price, and Month. Let me sort the table by clicking column headers. 3. A pie chart showing what percentage of total spending went to each category. 4. A bar chart comparing total spending in July vs August. 5. A question box where I can type things like "How much did I spend on milk?" or "What percentage of my total was on meat?" and get an instant answer based on the data — no internet or API call needed to answer, just look up the answer from the data you already extracted. Design it clean, modern, and uncluttered — plenty of white space, a simple color palette, readable fonts, and rounded cards. This is for my own personal use, so keep it as simple as possible to open and use. When you're done, tell me exactly which file to open and how.

Once Claude Code finishes, it will tell you which file to open — just double-click it to open your dashboard in your browser.

What you see in your browser is an app you create with Claude Code, on your own!

It is a locally hosted web app, meaning it exists only on your computer in your browser.

You can of course host it on Vercel, like this website is, for free.
