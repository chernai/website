Claude Code Project 1

Claude Grocery Project

A hands-on Claude Code project — follow along, copy the prompts and code below, and try it yourself.

A. Set Up

Follow along step by step — each card below is one step of the training. Instructions here are written for Windows/Microsoft computers.

Step 1

Create your training folder

Do this one yourself, before anything else gets installed. This is where we’ll throw photos of our grocery receipts, so that later on Claude Code can use its vision to read the images of the receipts that you put in there.

  1. Right-click on an empty part of your Desktop → New → Folder. Name it Claude Grocery Project.
  2. Open that folder. Inside it, create two more folders: one called July 2026 and one called August 2026.
Step 2

Install Claude Code

This is a one-time install. We’ll open a tool called PowerShell just to paste in one line — don’t worry about understanding it yet, we’ll properly cover terminals in the next step.

  1. Click the Start button (Windows logo, bottom-left), type PowerShell, then open Windows PowerShell.
  2. Copy the line below, right-click inside the PowerShell window to paste it, then press Enter:
    irm https://claude.ai/install.ps1 | iex
  3. Wait for it to finish, then close the window.

Then, create your free Claude account

You’ll need this to log in. It’s free to sign up, no credit card needed, and new accounts get a small amount of free credit — plenty to read a few receipt photos with.

  1. Go to platform.claude.com in your browser.
  2. Click Sign up (top-right), then enter your email and create a password — or sign up with your Google account.
  3. Check your inbox and click the verification link if you’re asked to.
  4. That’s it — your account is ready, with free credit already applied.
Step 3

Open a Terminal

A terminal is just a window where you type commands instead of clicking. We’ll use it for everything from here on, so let’s get comfortable opening one.

  1. Click the Start button, type Terminal, then open Terminal (or Windows Terminal, if that’s what shows up).
  2. A window with a blinking cursor will open — that’s it, you’re in.

Handy shortcut: in any File Explorer window, click the address bar, type wt, and press Enter — it opens a terminal already sitting in that folder.

Step 4

Learn a few basic commands

Type these into the terminal you just opened, one at a time, pressing Enter after each:

pwd
Where am I?
ls
What’s here?
cd foldername
Go into a folder
cd ..
Go back up one folder

For cd foldername, swap in a real folder name — e.g. cd Desktop.

Step 5

Open Claude Code in the Claude Grocery Project folder

Now let’s put it all together.

  1. In your terminal, go to your Desktop:
    cd Desktop
  2. Then go into your project folder:
    cd "Claude Grocery Project"
  3. Now start Claude Code:
    claude
  4. The first time you do this, your browser will open asking you to log in. Sign in with the account you created in Step 2. Once you see “Login successful”, come back to your terminal window — Claude Code is now ready to use.

Because you started it inside the Claude Grocery Project folder, Claude Code can now see your July 2026 and August 2026 folders — and any receipt photos you drop into them.
